# Phishing URL Detector – Explainable Phishing URL Detector

Phishing URL Detector is a client-side cybersecurity tool that analyzes URLs and explains
why a link may be suspicious.

## Features

- Suspicious IP address detection
- @-symbol deception detection
- Punycode/homograph detection
- Typosquatting detection
- Suspicious TLD detection
- URL shortener detection
- Phishing keyword detection
- Redirect and encoding detection
- Risk scoring
- Explainable security findings
- URL segment highlighting

## How it works

1. User enters a URL.
2. URL Lens parses its structure.
3. Multiple security heuristics are evaluated.
4. Findings are assigned severity levels.
5. A combined risk score is generated.
6. The tool explains the detected red flags.
